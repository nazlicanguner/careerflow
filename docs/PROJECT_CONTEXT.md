# CareerFlow - Project Context

## Product Vision
CareerFlow is a full-stack web application that helps jobseekers manage companies, job applications, interviews, and follow-up tasks in one place.

## Target User
An active jobseeker managing multiple applications and interview processes.

## Problem Statement
Job-search information is often scattered across job boards, emails, calendars, and notes. CareerFlow provides a clear view of the complete application pipeline and upcoming actions.

## MVP Scope
- Manage companies
- Create, update, view, and delete job applications
- Track application status
- Manage interviews linked to applications
- Manage follow-up tasks linked to applications
- Display a dashboard with key application metrics
- Search, filter, sort, and paginate applications
- Validate user input and provide clear error messages

## Out of Scope
- Authentication and multi-user roles
- LinkedIn or email integration
- File uploads
- Calendar synchronisation
- AI-based application generation

## Planned Technology Stack
- Backend: Java 21, Spring Boot, Maven
- Database: PostgreSQL
- Frontend: Angular and TypeScript
- API documentation: OpenAPI / Swagger
- Testing: JUnit and Mockito
- Containerisation: Docker Compose
- Version control: Git and GitHub
