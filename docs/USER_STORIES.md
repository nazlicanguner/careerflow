# CareerFlow - User Stories

## US-01: Manage Companies
As a job seeker, I want to create, view, update, and delete company records so that I can organise applications by employer.

## US-02: Create Job Applications
As a job seeker, I want to create an application linked to a company so that I can track a specific role and its details.

## US-03: Track Application Status
As a job seeker, I want to update an application's status so that I can see where I am in the hiring process.

Statuses:
- Saved
- Applied
- Screening
- Interview
- Offer
- Rejected
- Withdrawn

## US-04: Search and Filter Applications
As a job seeker, I want to search, filter, sort, and paginate applications so that I can quickly find relevant records.

## US-05: Manage Interviews
As a job seeker, I want to record interviews linked to an application so that I can prepare for and review each interview stage.

## US-06: Manage Follow-up Tasks
As a job seeker, I want to create and complete follow-up tasks linked to an application so that I do not miss important actions.

## US-07: View a Dashboard
As a job seeker, I want to see key metrics, upcoming interviews, and pending tasks on a dashboard so that I can understand the current state of my job search.
